【中文】

1. 打开
   先完整解压压缩包（Windows：右键 → 全部解压缩），
   再双击文件夹里的「VAULT配置器.html」，用 Chrome、Edge 或 Safari 打开。

2. ★ 导入你购买的 3D 模型文件夹 ★
   网页打开后，点右上角「未连接打印文件夹」，
   在弹窗里点「把整个模型文件夹拖到这里，或点击选择文件夹」，
   选择你自己购买的 VAULT 3D 模型文件夹（也可以直接把文件夹拖进去）。
   不导入就只能用 4 款体验单元，也无法导出打印文件。
   模型文件只在你的电脑上读取，不会上传。

3. 开始使用
   点左侧卡片添加单元，连续点击一层层往上叠；底部会自动生成打印清单。


[English]

1. Open
   Fully extract the zip first (Windows: right-click -> Extract All),
   then double-click "VAULT配置器.html" and open it with Chrome, Edge or Safari.

2. * Import the 3D model folder you purchased *
   Once the page is open, click "未连接打印文件夹" (no print folder
   connected) at the top right, then click "把整个模型文件夹拖到这里，
   或点击选择文件夹" (drop the model folder here, or click to choose)
   and select the VAULT 3D model folder you bought (or drag it onto it).
   Without it you only get 4 demo units and cannot export print files.
   Model files are read on your computer only and are never uploaded.

3. Start building
   Click a card on the left to add a unit; keep clicking to stack upward.
   The print list at the bottom updates automatically.
