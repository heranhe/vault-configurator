## 统一规则

1. 一个可视零件组只引用一个 STL。文件内含的多件分别拆出，每个实物显示 `1/N`，有独立锚点、引线、高亮和爆炸位置。
2. 螺栓头与螺栓杆是一颗实物，使用 `blocksPerPiece: 2` 归为一颗并编号。
3. 打印份数为重复打印整个 STL 的次数；实物总数为打印份数乘每份件数。成套文件不能重复按件数打印整份。
4. 齿条和分隔片支持按需选择，清单与显示、装配步骤同步更新。
5. 外购五金只进入采购数量及装配示意；定位工装进入打印清单但不留在成品装配图中，同方案共用。

## 产品边界

本次核对当前支持的抽屉、收纳箱、顶盖、双轮底座和固定支脚方案。墙挂、洞洞板、背板加固、伸缩拉杆以及四脚轮等未提供配置入口的改装方案，详见 04/05 记录，不会自动把这些可选方案的配件计入其他方案。总说明中的外部 Gridfinity 收纳盒不属于固定打印清单。

## 验证入口

`npm test`、`npm run build`。公共核对覆盖 380 种规格的文件单独引用、打印实物数与场景实例数、唯一编号和装配最终位置，并验证复用工装和顶盖五金等汇总规则。
