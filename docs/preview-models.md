# 本地模型优先，四款基础体验

正式地址：https://vault3d.pages.dev/（2026-10-23 已部署）。本项目不再采用整库在线预览或 R2 模型托管。

## 内置范围

只提供 S5 · 1F / 2F 抽屉（empty）和 S5 · 1F / 2F 收纳箱（flat）。
四款单元共用 31 个预览文件，gzip 后合计约 21.03MB；包括独立显示所需的钥匙帽、滑块、限位块和齿条。
仅随网站发布 `public/demo-models`，原始 STL 不放进网站。

```bash
npm run demo-models -- "<包含 01. DRAWERS 的模型包内层目录>"
```

生成命令只根据 `src/models/demo.ts` 中四款规格寻找需要的零件，不会处理整库。
输出包括内容哈希命名的 `.mesh.gz`、manifest 和体积报告。此目录是生成资产，需要随部署包发布。
`.mesh.gz` 是应用层 gzip，服务端不要设置 `Content-Encoding: gzip`，由前端解压。

## 使用流程

- 首屏中央明确提示导入模型，下面提供四款体验入口，不自动弹出旧的新手面板遮挡入口。
- 本地服务支持填写目录路径；纯静态网页版通过选择或拖入文件夹授权读取，无法用任意文本路径直接访问磁盘。
- 零件库不区分体验款和全部规格：未导入时只显示四款基础单元，导入后自动显示完整分类与规格筛选；断开后恢复四款。仅这四款会请求内置轻量文件。
- 同时最多下载三个预览零件，重复使用共用请求，OPFS 缓存命中后不再下载网格。
- 导入后优先读取用户本地 STL，并沿用后台简化和磁盘缓存。
- 打印导出始终要求用户自己的原始 STL。体验网格不能替代打印文件。

## 验证

`npm test`、`npm run build`。测试覆盖模型文件读取匹配、方案保存、按需加载、并发限制、缓存命中和禁止非体验规格在线加载。
